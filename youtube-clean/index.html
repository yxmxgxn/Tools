YouTube URL整形

YouTubeのURLから、共有トラッキング(si=)やプレイリストなどの余計なパラメータを消して整形します。
よくある「URLをきれいにするやつ」と違い、再生開始位置(t=)だけは残します。「この瞬間から見て」を保ったまま共有できます。
整形後のURLを開く

ブックマークレット

YouTubeの動画ページで実行すると、いま開いている動画の整形済みURL(t=付き)をクリップボードにコピーします。
PCでは下のボタンをブックマークバーにドラッグして登録してください。スマホでは「コードをコピー」して、適当なページをブックマークしてから編集でURL欄に貼り付けてください。
YouTube URLをコピー

その他のURL（汎用パラメータ除去）

YouTube以外のURLは、こちらでトラッキング用のパラメータ（utm_*・fbclid・gclid・si など）を除去します。
機能に必要なパラメータを壊さないよう、既知のトラッキング用パラメータだけを消して、それ以外はそのまま残します。
Amazon のURLだけは特別扱いで、商品ID(ASIN)だけを抜いた最短形 amazon.co.jp/dp/ASIN にします。
整形後のURLを開く

ブックマークレット（汎用）

YouTube以外のページで実行すると、そのページのURLからトラッキング用パラメータを除いたものをクリップボードにコピーします。
URLをきれいにしてコピー

ブックマークレット（強力モード）

クエリ(?以降)をすべて消したものをコピーします。トラッキングが独自パラメータで残る場合はこちら。
クエリを全部消してコピー

消すもの / 残すもの（YouTube整形）

  • 残す: 動画ID と 再生開始位置(t= または start=)。1m30s のような表記も秒(90)に統一します。
  • 消す: si=(共有トラッキング)、pp=、feature=、ab_channel=、list=/index=(プレイリスト文脈)、utm_* など、動画の再生に不要なものすべて。
  • watch / youtu.be / shorts / live / embed、m.・music. のURLに対応。
  • 短縮URL(youtu.be): オフだと youtube.com/watch?v=ID&t=90s(長い形・s付き)、オンだと youtu.be/ID?t=90(youtu.be・s無し=YouTube純正の短縮リンクと同じ形)。
  • 時間指定(t=)を消す: オンにすると再生開始位置を落として、動画のみのURLにします。
