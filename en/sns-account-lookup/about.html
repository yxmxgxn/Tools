How to Use It & How It Works

Find the Account from a Post URL

This tool makes network requests. The URLs and IDs you enter are sent through this site's server to Instagram, X, Threads and TikTok to look them up. This is different from the other tools on this site, which run entirely inside your browser.

What this tool does

From the URL (or ID) of a post on Instagram, X, Threads or TikTok, it tells you:
  • the current username
  • today's URL (the form that includes the username)
  • the time it was posted (calculated from the ID, so it is accurate to the second)
Use it when the username is missing from a URL, when an old URL has a username that has since changed, or when all you have is an ID.

How to use it

  1. Paste the URL (or ID) of the post you want to look up into the box. Put one per line; you can look up to 5 at a time.
  2. Press "Look up" to see the service, the current username, today's URL and the time it was posted.
  3. Use "Copy username" and "Copy URL" to copy the results.
You can also enter just an ID or code instead of a URL (see "How a bare ID is identified" below).

How a bare ID is identified

  • Digits only: X and TikTok IDs both have the time embedded. The number is converted to a time using each service's rule, and the one that gives a plausible year is used. For current IDs, only one of them is plausible.
  • An alphanumeric code of 10–11 characters: Instagram and Threads codes look the same, so both are queried and whichever one finds the post is reported.

How it works

Each service opens the same post from its ID alone, even if the username part of the URL is wrong, and then rewrites the address to one containing the correct (current) username. This tool just reads where it was rewritten to.

This finds the current name. It cannot tell you the name the account had when the post was made. If the account has been renamed, the new name is shown.

How network requests and your input are handled

  • The URLs and IDs you enter are received by this site's server, which then queries Instagram, X, Threads or TikTok. Your own computer does not connect to those services directly.
  • The server builds the address it queries using only the ID extracted from your input. It never connects to the URL you typed.
  • Your input and the results are not stored. The program behind this tool doesn't write them to a log either.
  • To prevent overuse, there is a rate limit (up to 8 lookups per minute per person, plus an overall cap). For that purpose only, information about where the request came from is used briefly, in Cloudflare's rate-limiting mechanism and in the server's memory, solely to count requests.
  • There is no login, no password and no account linking of any kind.
  • Nothing about you is saved in your browser.

Cloudflare, which serves this site, may keep ordinary access records. The program behind this tool does not store what you enter.

Notes and limits

  • Only public posts are covered. Posts from private accounts and deleted posts come back as "Not found".
  • A service may refuse requests from this server. That also shows up as "Not found".
  • None of these services' mechanisms are officially published. If they change without notice, the tool may stop working.
  • TikTok is read from inside the page, so it is more likely than the other three to break when TikTok changes something.
  • You can look up at most 5 at a time, and there is also a cap on lookups within a given period.
  • If an ID has the wrong number of digits or characters (Instagram and Threads codes are 10–11 characters, X IDs are 15–19 digits, TikTok IDs are 19 digits), the tool explains why, such as "too short" or "too long", before querying any service. It never tries to pad an ID that is one character short, because that would add extra requests to the services.
  • Bluesky isn't supported, because the author of a post can't be found from the ID alone.
