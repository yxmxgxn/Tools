SNS Post Time Viewer

Paste a post URL from X, Instagram, TikTok, Threads, Bluesky, Misskey or Mastodon to see the post time (timestamp, in Japan Standard Time) and the account name. Instead of a rough "2 days ago" or "1 year ago", you get the exact time to the second.
The time is worked out from the ID in the URL, so you don't need to open the post. Paste several at once, one per line.
YYYY year (4 digits) · YY year (2 digits) · MM / M month · DD / D day · HH / H hour · mm minute · ss second · ddd day of week (Tue)
Two-letter tokens are zero-padded (09); one-letter tokens are not (9). Text inside [ ] is printed as is.

    Bookmarklet

    Run it while you have a post open on a supported service to show the exact post time (to the second) and the account name on the spot. It's handy when the site only shows a rough "2 days ago", "3-4" or "1 year ago". Use "Copy" to copy the time.
    It doesn't open this tool's page, and the calculation happens right there, so nothing is sent anywhere. The display format is fixed at yyyy/mm/dd hh:mm:ss (JST).
    On a PC, drag the button below to your bookmarks bar. On a phone, tap "Copy code", bookmark any page, then edit the bookmark and paste the code into the URL field.

    Supported URLs

    • X: x.com/username/status/number (twitter.com works too)
    • Instagram: instagram.com/p/code, /reel/code, /reels/code, /stories/username/number (the link in the result opens in the form /i/p/code)
    • TikTok: tiktok.com/@username/video/number (/photo/ works too)
    • Threads: threads.com/@username/post/code (threads.net works too)
    • Bluesky: bsky.app/profile/handle/post/code
    • Misskey: server/notes/ID (servers other than misskey.io work too)
    • Mastodon: server/@username/number (servers other than mstdn.jp work too)
    Misskey URLs don't contain the account name, so only the time is shown.
    Instagram URLs usually don't contain the account name either. If you open the link in the result (/i/p/code), the URL is rewritten to the form instagram.com/username/p/code; paste that back in to also see the account name. Copying the link on the date of the post gives the same form.
    The link opens in the /p/ form because /reel/ and /reels/ redirect to the Reels continuous-play screen, and for photo posts that can swap in a different reel.
    For TikTok short URLs (vm.tiktok.com/…) and X's t.co/… links, open them in your browser first and paste the long URL that appears.

    How it works

    On every one of these services, the post time is embedded in the upper bits of the post ID. This tool just extracts that part of the ID and turns it back into a time. It doesn't connect to anything.
    • X: shift the ID right by 22 bits to get the milliseconds elapsed since November 4, 2010.
    • Instagram: the code in the URL is the ID written in base 64 (A-Z a-z 0-9 - _). Convert it back to a number and shift it right by 23 bits to get the milliseconds elapsed since August 24, 2011.
    • TikTok: shift the ID right by 32 bits to get Unix time (seconds) directly.
    • Threads: the same mechanism as Instagram.
    • Bluesky: the last 13 characters of the URL are base 32 (2-7 a-z). Convert them back to a number and shift it right by 10 bits to get Unix time in microseconds.
    • Misskey: the ID format depends on the server's settings. In the format used by most servers (such as misskey.io), reading the first 8 characters as base 36 gives the milliseconds elapsed since January 1, 2000. Other formats (meid, ulid, objectid) are told apart by length and character set and calculated as well.
    • Mastodon: shift the ID right by 16 bits to get Unix time (milliseconds). Posts from before 2017 use sequential IDs and can't be calculated.
    The time shown is "the moment the ID was issued". For scheduled posts or posts made from a draft, it can differ slightly from the time shown on the post.
    The account name is taken as written in the URL. On X and Instagram, the same post opens even if the username part is different (Instagram rewrites the address to the correct author after it opens), so with a URL from before a rename, or a URL edited by hand, the name may not match the real author. To be sure, open the post from the link in the result and check.

    Notes

    This tool calculates from the ID mechanisms each service uses right now. These mechanisms aren't officially published, and a service can change them without notice.
    The times shown are a guide. Accuracy isn't guaranteed, so if you need a definitive time, check it against the post itself.
    URLs with extra characters in the ID, or the wrong number of characters, are reported as errors. However, a single wrong character that keeps the length the same, or a truncated ID whose length happens to be valid for an older post (such as 10 characters on Instagram), can't be detected and will be calculated as a different time.
