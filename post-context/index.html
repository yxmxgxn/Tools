Xポスト前後検索

XのポストURLを貼るだけで、そのポストの前後に投稿者が何を言っていたかを検索するコマンドとリンクを生成します。
ポストIDから投稿時刻を逆算するので、日時を手入力する必要はありません。時刻はポストの瞬間を中心に秒単位で正確に切り出します。

こんなときに

  • あるポストを見て「この人、この日の前後に何を言ってたんだろう」と気になったとき。前後の流れをまとめて追えます。
  • 「RP > 〇〇」のようなRTへの感想だけが流れてきて、何をRTしたのか分からないとき。「RTも含める」をオンにして前後検索すると、RTした時刻でそのRTがタイムラインに並ぶので、感想の対象を特定できます(XのUI変更でRTとポストが別々に表示され、RT後の感想が読み取りにくくなった問題の回避に使えます)。

仕組み

XのポストIDには投稿時刻がミリ秒単位で埋め込まれています。このツールはIDから時刻を逆算し、検索演算子 since: / until: に日本時間付きの日時(2026-07-15_15:32:28_JST のような形式)を渡して前後の期間を切り出します。
_JST を明示するのでUTCとの時差の影響を受けず、ポストの瞬間を中心とした秒単位で正確な範囲になります。日時形式なので、検索したあとに検索窓で日付の数字を書き換えれば範囲を広げたり狭めたりも簡単です。
「unix秒形式で出力」をオンにすると since_time: / until_time:(unix秒指定)の形式になります。精度・時差の扱いは同じです。
なお、検索はX上で行われるため、鍵アカウント・削除済みポストは表示されません。URLのユーザー名部分は現在のものと異なる場合があります(改名時など)。
