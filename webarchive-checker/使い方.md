# webarchive_checker_v3.py の使い方

TSVの各行のURLについて Wayback Machine（web.archive.org）のスナップショットを探します。
Claude Haiku に「記事として読める状態か」を判定させ、OKならそのアーカイブURLを `WebArcive` 列に書き込みます。

---

## 1. 準備（初回だけ）

### Pythonライブラリ
```
pip install requests trafilatura anthropic
```

### APIキー
Anthropic の APIキーを環境変数 `ANTHROPIC_API_KEY` に設定します。未設定だとすぐ終了します。

- Mac / Linux
  ```
  export ANTHROPIC_API_KEY=sk-ant-...
  ```
- Windows（PowerShell）
  ```
  $env:ANTHROPIC_API_KEY="sk-ant-..."
  ```
- Windows（コマンドプロンプト）
  ```
  set ANTHROPIC_API_KEY=sk-ant-...
  ```

ターミナルを閉じると消えます。毎回設定するか、OSの環境変数に登録してください。

---

## 2. 入力ファイルの作り方

**URLを改行で並べただけのファイルは使えません。**
タブ区切り（TSV）で、1行目にヘッダー（列名）が必要です。

### 列

| 列名 | 必須か | 内容 |
|---|---|---|
| `URL` | **必須** | 調べる記事のURL |
| `WebArcive` | **必須** | 結果の書き込み先。最初は空でOK。`WebArchive` という綴りでも認識する |
| `Date` | 任意 | 記事の日付。この日付**以降**のスナップショットだけを探す |
| `Title` | 任意 | 記事タイトル。Haikuが「目的の記事と同じか」を判定するのに使う。**あると精度が上がる** |
| `ID` | 任意 | レポートに載るだけ |

- 列の順番は自由です。上記以外の列があっても、そのまま残ります。
- 列名は大文字・小文字も含めて正確に書いてください（`url` や `title` は認識されません）。

### Date の書き方
数字を区切りで並べれば読み取ります。
- `2018/02/20`、`2018-02-20`、`2018.2.20` → 2018年2月20日以降
- `2012/06` → 2012年6月以降
- `2012` → 2012年以降
- 空欄 → 期間の指定なし

### 例（列の間は**タブ**）
```
ID	URL	Date	Title	WebArcive
1	https://example.com/interview/123	2018/02/20	〇〇さんインタビュー	
2	https://example.com/report/456	2012/06	△△イベントレポート	
3	https://example.com/news/789			
```

URLだけで実行する最低限の形:
```
URL	WebArcive
https://example.com/a
https://example.com/b
```
後ろの列が足りない行は、空欄として扱われます。

### ファイル作成のコツ
- Excel やスプレッドシートで表を作り、「タブ区切りテキスト（.tsv / .txt）」で保存するのが簡単です。
- 文字コードは **UTF-8** にしてください（BOM付きでも可）。Shift_JIS で保存すると読めません。
  - Excel の場合は、表を Googleスプレッドシートに貼ってから「ファイル → ダウンロード → タブ区切り形式(.tsv)」で保存すると確実です。
- URL が空の行は処理しません。

---

## 3. 実行

```
python webarchive_checker_v3.py 入力.tsv
```
→ 同じフォルダに `入力_updated.tsv` ができます。

### オプション
```
python webarchive_checker_v3.py 入力.tsv 出力.tsv     # 出力先を指定
python webarchive_checker_v3.py 入力.tsv --no-save    # Save Page Now（新規保存）をしない
```

`--no-save` を付けると速くなります。そのかわり、既存のスナップショットが無いURLは何もせず飛ばします。

---

## 4. 1行ごとの処理の流れ

1. `Date` 以降の、ステータス200のスナップショットを新しい順に**最大3件**取り出す（内容が同じものは1件にまとめる）
2. 新しいものから順に本文を取り出す
   - 取得に失敗した、または本文が200字未満 → NG。次の候補へ
   - それ以外 → Haiku が判定する。OKならそこで確定
3. 全部NG、またはスナップショットが無い場合 → **Save Page Now** で今のページを新しく保存し、同じように判定する（`--no-save` なら行わない）
4. 結果を書き込み、ファイルを保存する

Haiku がNGにする例: 404やエラーページ、トップページや一覧ページへの転送、本文が無い、ログインが必要なページ、会員限定の記事、文字化け、別の記事

---

## 5. 出力ファイル

### `入力_updated.tsv`
元のTSVと同じ形式です。取れた行だけ `WebArcive` 列にURLが入ります。
```
https://web.archive.org/web/20180305123456/https://example.com/interview/123
```

### `入力_updated_report.tsv`
今回処理した行の結果一覧です。

| 列 | 内容 |
|---|---|
| ID | 入力のID列（無ければ空） |
| URL | 元のURL |
| 結果 | OK / NG |
| 理由 | Haikuの判定理由や「スナップショットなし」「本文が短い(85字)」など |
| WebArchive | 書き込んだURL（NGなら空） |

**レポートは実行するたびに上書きされます。** 残したい場合はファイル名を変えておいてください。

---

## 6. 取れなかった場合

- **`WebArcive` 列は空欄のまま**になります。理由はレポートで確認できます。
- 同じコマンドをもう一度実行すると、**空欄の行だけ**もう一度試します。
  Save Page Now で保存した直後はまだ見られないこともあるので、時間をおいて再実行すると取れる場合があります。
- どうしても取れない行は手動で確認してください。

---

## 7. 途中で止めた・再開したい

- `Ctrl + C` でいつでも止められます。1行処理するごとに保存しています。
- 再開するときは**同じコマンドをそのまま実行**します。`_updated.tsv` が既にあれば、そこから読み込んで続きを処理します。
- `WebArcive` 列に値が入っている行は処理しません。

### 注意
- 再開中は**元の入力TSVではなく `_updated.tsv` が読まれます**。
  入力TSVに行を追加・修正したときは、`_updated.tsv` に同じ変更をするか、`_updated.tsv` を消してから実行してください。
  消すと、すでに取れた分も最初からやり直しになります。
- 特定の行をやり直したいときは、`_updated.tsv` のその行の `WebArcive` を空にしてから実行します。

---

## 8. 時間と料金の目安

- 1行あたり数秒〜数十秒かかります。Save Page Now を使う行は1〜2分かかることもあります。
- Wayback Machine は混雑すると 429 や 5xx のエラーを返します。そのときは10秒、20秒、30秒…と待って、最大4回まで自動で再試行します。ログに `… 秒待って再試行` と出るのは正常です。
- 最後に、Haikuの呼び出し回数と**おおよその料金（ドル・円）**を表示します。Haiku 1回の判定は約0.2〜0.4円です。
  - 料金や為替レートはスクリプト冒頭の `PRICE_IN` / `PRICE_OUT` / `YEN_PER_USD` で変更できます。

---

## 9. 調整できる設定（スクリプト冒頭）

| 名前 | 初期値 | 意味 |
|---|---|---|
| `MODEL` | `claude-haiku-4-5` | 判定に使うモデル |
| `CANDIDATES` | `3` | 1つのURLで試すスナップショットの数（新しい順） |
| `BODY_CHARS` | `1500` | Haikuに渡す本文の文字数 |
| `PRICE_IN` / `PRICE_OUT` | `1.00` / `5.00` | 100万トークンあたりの料金（USD） |
| `YEN_PER_USD` | `150` | 円に換算するレート |

---

## 10. よくあるエラー

| メッセージ | 原因と対処 |
|---|---|
| `ANTHROPIC_API_KEY が設定されていません` | 手順1でAPIキーを設定する |
| `URL列またはWebArcive列が見つかりません` | ヘッダーの綴りを確認する。区切りが**タブ**になっているか（カンマ区切りのCSVは不可）も確認する |
| `ModuleNotFoundError` | `pip install requests trafilatura anthropic` を実行する |
| `UnicodeDecodeError` | 入力ファイルを UTF-8 で保存し直す |
| `✗ 保存失敗` | Save Page Now が混んでいる、またはサイトが保存を拒否している。時間をおいて再実行する |
